# 记账小程序

微信小程序 + Skyline + 本地存储的个人记账工具。零后端、零 npm 依赖、离线可用。

规划见 [PLAN.md](./PLAN.md)，本文档只讲**已经实现的东西**和**怎么继续往上加**。

| 外观（上传图片做全屏背景） | `pages/appearance` | ✅ |
| 年度账单（全年结余 + 按月收支表） | `pages/bill` | ✅ |
| 购物清单（想买但暂时买不起的东西） | `pages/wishlist` | ✅ |

设计上的既定选择：

- **金额全部用整数「分」**，展示层才格式化，杜绝浮点误差。
- **流水按月分片存储**（`acc:txn:YYYY-MM`），首页/统计只反序列化需要的月份。
- **图表不用 canvas**，柱状图与占比条都是 view + flex 手绘，避开 Skyline 的 canvas 版本差异。
- **不使用原生 tabBar**，用 `app-tabbar` 组件 + `wx.reLaunch` 切页，样式可控且不受 tabBar 配置限制。
- **弹层不用 `position: fixed`**，用 `.page` 内的 `absolute` 覆盖层。

## 二、目录与分层

```
utils/                 ← 纯逻辑，页面不碰 storage
  storage.js           唯一调用 wx.storage 的适配层（换云端的替换点）
  db.js                集合级读写 + 内存缓存
  store.js             业务仓储：账本/分类/流水/预算/导入导出，变更发 bus 事件
  metrics.js           纯函数指标：汇总/分组/占比/预算进度（无 wx 依赖，可单测）
  money.js             分↔元、千分位、输入格式化
  date.js              日期/月份字符串工具
  amount-input.js      键盘输入状态机
  seed.js              内置账本与分类模板
  migrations.js        版本迁移表
  version.js           数据版本号（单一来源）
  icons.js             内置图标表（key → svg 路径）
  media.js             选图 / 压缩 / 落盘到本地用户目录
  bus.js               事件总线
components/
  navigation-bar/      已有（自定义导航栏）
  app-tabbar/          底部标签栏
  amount-keyboard/     数字键盘（只抛按键，不含金额状态）
  category-picker/     分类网格选择
  calendar-panel/      自绘日历（选日期）
  month-calendar/      月历（每日金额热度图，统计页用）
  time-panel/          自选时刻（24 小时 × 60 分钟网格 + 常用快捷）
  txn-item/            单条流水
  bar-chart/           柱状趋势图（view 绘制）
  ratio-bar/           占比条
  sheet/               底部弹层
  empty-state/         空态
  page-bg/             全屏背景层（fixed + 100vh，内容层 z-index 更高）
  app-icon/            统一图标：上传图 > 内置 SVG > emoji 兜底
pages/                 11 个页面
```

数据流：`页面 → store（业务）→ db（集合）→ storage（wx.storage）`，反向通过 `bus.emit('change')` 通知页面刷新。
页面里没有一处直接读写 storage，也没有一处直接操作账本/分类数组。

## 三、扩展点（重要）

### 1. 换成微信云开发 / 自有后端
只需要动两个文件：

1. `utils/storage.js` —— 把 `read/write/remove/listKeys` 换成云数据库调用；
2. `utils/db.js` —— 如果接口变成异步，把 `store.js` 的调用点加 `await`（`store` 内部已按「集合」封装，改动集中）。

页面、组件、`metrics.js` 都不需要改。

### 2. 给流水加字段（比如「标签」「附件」）
1. 在 `pages/record` 加输入项，`store.addTxn` 的 payload 里带上新字段；
2. 在 `utils/migrations.js` 的 `steps` 末尾追加：

```js
function toV3() {
  // 给老数据补默认值
}
```
3. 把 `utils/version.js` 的 `VERSION` +1。`steps.length` 必须与它相等（不一致会在控制台告警）。老用户下次启动会自动迁移。

### 3. 加页面
1. 建 `pages/xxx/` 四个文件；
2. 在 `app.json` 的 `pages` 里注册（第一项是启动页）；
3. 需要底部标签就改 `components/app-tabbar/app-tabbar.js` 的 `TABS`。

### 4. 加分类图标
改 `pages/categories/categories.js` 的 `EMOJIS` 数组即可，不需要图片资源。

### 5. 改主题
`app.wxss` 里 `page { --c-* }` 一组 CSS 变量。改完全局生效——新组件请用 `var(--c-expense, #E4572E)` 这种带兜底的写法。

### 6. 加/换图标
图标是彩色 PNG，放在项目根的 `assets/` 下，按用途分：`tabbar / mine / cat / alt / book`。

1. 把 PNG 丢进对应目录（**路径必须是 ASCII**）
2. 在 `utils/icons.js` 的 `CATEGORY_FILES`、`ALT_FILES` 或 `MAP` 里加一行
3. 用 `<app-icon icon-key="你的key" emoji="兜底 emoji" size="{{40}}" />` 引用

`app-icon` 的优先级是：用户上传的图片 > 内置图标 > emoji。图片加载失败会自动降级成 emoji，不会出现空白格。

> 两个坑：① 不要用 SVG，Skyline 的图片管线不处理本地 `.svg`，请求会 500；② 资源路径不要带中文，Skyline 的资源服务对百分号编码的中文路径同样返回 500。

## 四、数据模型

```js
// acc:meta
{ version: 2, activeBookId: 'bk_default', currency: 'CNY', carryBudget: true,
  background: 'wxfile://usr/uploads/bg_....jpg' }   // 可选，背景图

// acc:books
{ id, name, emoji, iconPath: '', color, members: ['我'], archived: false, order, createdAt }

// acc:cats  （每个账本一套，互不影响）
{ id, bookId, name, emoji, iconPath: '', type: 'expense'|'income', color, order, builtin, createdAt }

// acc:txn:2026-10   （按月分片）
{ id, bookId, type, amountCents, categoryId, date: '2026-10-30', time: '20:15',
  note, member, createdAt, updatedAt, deleted }

// acc:months → ['2026-09', '2026-10']   月份索引，启动时按实际 key 重建
// acc:budgets → { '2026-10|bk_default': { totalCents, byCategory: { catId: cents } } }

// acc:wishes  （购物清单，独立于账本）
{ id, name, priceCents, note, done: false, doneAt: 0, createdAt, updatedAt }
```

金额单位是**分**；日期是 `YYYY-MM-DD`、时刻是 `HH:mm` 字符串（可直接比较排序）。
同一天内按 `time` 倒序排列，时刻相同时再按 `createdAt` 倒序。

## 五、怎么跑起来

1. 微信开发者工具 → 导入项目 → 选 `D:\dsh项目\记账小程序`，appid 已配置；
2. 基础库选 **3.0.0 以上**（`app.json` 里 Skyline 要求 `sdkVersionBegin: 3.0.0`）；
3. 编译。首次启动会写入默认账本「日常」和 15 个内置分类。

> `project.private.config.json` 里我把 `skylineRenderEnable` 打开了，与 `app.json` 的 `renderer: "skyline"` 保持一致。如果页面出现异常，可以先把它改回 `false` 用 webview 渲染对比——本项目的布局（flex + absolute）两种渲染器都能跑。

> **开发注意**：新增、删除、重命名文件或目录时，如果开发者工具正开着，它的文件列表不会自动更新，会报 `WXML file not found`、`module not defined`，或者组件渲染成空白。**关闭项目重新打开**即可，不用清缓存。这个坑这个项目里已经踩了五次，改动文件结构后一律重启。

## 七、已知限制 / 待验证

1. **未在真机验证**：本次开发环境 shell 不可用（`pwsh` 返回 `0xC0000142`），无法编译或跑 lint，所有代码只做了静态自检。首次编译若有报错，多半是 Skyline 的个别样式属性（如 `overflow`/`max-lines`、`env()`），改动集中在 wxml/wxss，不涉及数据层。
2. **`scroll-view type="list"`** 是 Skyline 的写法；webview 下会被忽略但仍能滚动，属于预期降级。
3. **本地 10MB 上限**：约 5 万条流水；写满时会弹窗引导导出。
4. **明细搜索（关键词）尚未做 UI**：`store.listTxns({ keyword })` 已支持，只差页面入口。
5. **图片只在本地**：背景图和自定义图标是本地文件，JSON 备份只记录路径。换手机恢复备份后图片不会跟过来（导入时会把失效引用清空，回到 emoji），需要在新设备重新上传。

**v3.7：分类占比支持饼图、月度趋势支持折线**

- 分类占比右上角加了「列表 / 饼图」切换。饼图是环形图，**点环上的任意色块**会按落点角度反查是哪个分类，直接打开该分类的明细；下面还有图例，点名称同样生效。
- 月度趋势加了「柱状 / 折线」切换。折线是**纯 view 画的**（圆点 + 旋转的细线段），不依赖 canvas。
- 饼图用 `canvas type="2d"` 绘制（`components/pie-chart`），中心挖空成环形，尺寸按设备像素比放大，避免糊。
- 两个切换的状态只存在页面里，不落盘。

**v3.6：导出/导入支持多种格式**

- 导出从 2 种变成 5 种，都走同一套筛选（账本 / 日期 / 分类）：
  - **CSV** 通用表格
  - **TSV** Excel 双击直接打开，不用选分隔符
  - **Markdown** 表格，带合计行，可贴进笔记 / Notion
  - **纯文本** 一行一笔，适合直接发给别人
  - **JSON** 全量备份（唯一不受筛选影响的）
- 导入支持 **CSV**：粘贴框自动识别格式（`{` 开头当 JSON，其余当 CSV）。
  - CSV 会按名字匹配账本和分类，找不到就自动新建；表头认「账本 / 日期 / 时间 / 类型 / 分类 / 金额(元) / 记账人 / 备注」，少几列也能导
  - 按「账本+日期+时间+类型+金额+分类+备注」去重，重复导入不会翻倍，导入完会提示新增多少、跳过多少
- 新增 `utils/csv.js`（解析）和 `utils/export-format.js`（生成各格式文本），格式逻辑不再散在页面里。

**v3.2：转场时长收到 200ms（已回退）**

- 结论：系统那 300ms 转场没有安全的自定义方式，维持原样。

**v3.1：tab 切换改用系统转场**

- v3.0 的自制滑动会**中间白屏**：旧页面滑出后已经被销毁，新页面要等 `reLaunch` 才能滑入，两段之间是空的。
- 改成系统转场：左滑用 `navigateTo`（新页从右滑入、旧页同时左移），右滑用 `navigateBack`（当前页右滑出、上一页同时回来）。两个页面同时动，没有空白。
- 页面栈里只有自己时（比如刚从 tabbar 点进来），右滑退不回去，退回瞬时切换。
- v3.0 的 `utils/slide.js` 已不再被引用，可以删除。

**v3.0：tab 切换加滑动动画（已废弃）**

- 自制两段式动画：旧页面滑出 → reLaunch → 新页面滑入。因中间存在空白期，已被 v3.1 取代。

**v2.9：左右滑动切换 tab**

- 四个 tab 页都支持手势：**左滑进入下一个 tab，右滑回到上一个**，在两端时不动。
- 识别逻辑在 `utils/swipe.js`：横向位移 ≥ 60px、且明显大于纵向位移（1.2 倍以上）、800ms 内完成才算滑动，避免和列表上下滚动、长按、点击冲突。
- tab 定义抽到 `utils/tabs.js`，tabbar 组件和手势共用一份，新增 tab 只改一处。
- 弹层打开时不会触发（弹层是 `position: fixed` 且挂在 `.page-body` 外面，触摸事件不落到手势监听上）。

**v2.8：导出支持范围筛选**

- 「导出备份」页新增**导出范围**：账本（当前 / 全部）、开始日期、结束日期、分类多选。
- 选「全部账本」时，多个账本的数据会**按日期+时间正序合并**成一张表，CSV 里多一列「账本」用来区分来源。
- 分类筛选按**分类名**匹配，所以跨账本合并时「餐饮」能对上所有账本里的餐饮。
- CSV 按当前范围导出，文件名带范围和日期，例如 `账单_全部账本_2026-09-01_2026-10-31.csv`。
- **JSON 备份保持全量**，不受筛选影响——它是用来恢复数据的，被裁剪过就不叫备份了。
- 页面上半部分的「符合条件 / 日期跨度」会随筛选实时更新，导出前能看到会导出多少条。

**v2.7：精简内置分类**

- 删掉「医疗」「理财」两个分类（它们没有对应图标，一直显示 emoji）。
